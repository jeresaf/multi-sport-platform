# Roles

Generated by `dotnet run --project backend/tools/SportsPlatform.Cli -- export-catalogues`; do not edit.
Defined in code in Identity's `IdentityRoles` (docs/architecture/authorization.md). Assignments store the
role code; the actions are those in `actions.md`. Account actions need no role.

**Actions** is what a role grants today; **Description** is the role's purpose, which later slices fill in
as they add actions.
